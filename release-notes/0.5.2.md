An installed embedding model is recognised as installed.

**Fixed**
- **"model not installed: nomic-embed-text" with the model installed.** Ollama lists a model pulled without a tag as `nomic-embed-text:latest`, and the plugin compared the names literally, so the startup Notice, the settings *Test connection* button, the model picker in the panel and the tuning advice all called the model missing (and the picker showed a spurious "(not installed)" entry). Names are now compared the way Ollama resolves them: case-insensitively and with `:latest` optional. `ollama pull nomic-embed-text` and `nomic-embed-text:latest` in settings are the same model.
