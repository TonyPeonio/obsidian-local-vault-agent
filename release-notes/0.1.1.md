Maintenance release to pass the Obsidian community directory's automated review.

- Releases are now built and attested by GitHub Actions from the committed lockfile, so the directory can verify the published `main.js` matches the source.
- `minAppVersion` raised to 1.7.2 (required by `Workspace.revealLeaf`).
- Upgraded the `diff` dependency past advisory GHSA-73rr-hh4g-fpgx.
- Replaced a regex lookbehind that older iOS versions do not support.
- Writes go through `Vault.process`; the vault's configured settings folder is respected instead of assuming `.obsidian`.
- Smaller lint-driven cleanups: window timers, no inline styles, typed JSON parsing, no deprecated setting-tab calls.

No functional changes to the agent, tools or search.
