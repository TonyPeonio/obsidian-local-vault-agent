The agent now works like a coding agent: it finishes the job, you can take any change back, and it can see the shape of your whole vault.

**Autonomy**
- Multi-note tasks run to the end in one message; the model no longer stops to ask "shall I proceed?". If a small model asks anyway, the agent answers yes for it (up to three times per message, never for a question that offers you a choice, and never after you rejected a change). A question gets an answer, not edits.
- A reply that cites notes which do not exist is sent back once with "search the vault first".
- For a task across several notes the model states a one-line plan first, then starts immediately.

**Undo**
- Every approved write is recorded with what it replaced. *Undo the agent's last change*, *Undo every change from the agent's last message*, an **Undo** button on each tool card, and `/undo` / `/undo-all` in the chat. Each revert is shown as a diff and applied only when approved. Deleted attachments up to 100 MB can be restored.

**Seeing the vault**
- The system prompt carries an outline of every note (folder, name, headings, tags), budgeted to the context window.
- **Note gists**: a one-sentence gist of every note, written by the chat model in the background (paused while you chat, cached by mtime) and shown in the outline instead of headings, so the agent knows what each note is about without reading it. Settings → Note gists; `/gists` rebuilds.
- **Conventions note** (`AGENT.md` by default): given to the agent on every message, like a CLAUDE.md. Settings → Conventions note → Create / open.
- Default context window raised to 32768; the chat footer shows context use and warns at 85%.

**Retrieval**
- `search_passages` returns the best-matching note *sections* verbatim (the index was already per heading; now the model sees it). `read_section` reads one heading's body. `find_in_note` locates lines in long notes. `edit_note` misses return the real lines containing the most distinctive word.

**Files and organisation**
- `list_files` and `delete_file` cover attachments (recordings, images, PDFs); `move_note` moves or renames notes and attachments with links updated.

**Chat**
- `@` attaches a note to your message (as `[[Note]]`; its content is included so no tool call is needed). `/` opens the command list: `/reformat`, `/summarize`, `/undo`, `/undo-all`, `/new`, `/gists`, `/index`, `/help`.
- **Copy conversation** copies the whole chat, tool calls included, as markdown.
- Default max tool calls per message raised from 15 to 40 (slider to 100).
