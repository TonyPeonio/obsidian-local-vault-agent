Two fixes found in live testing right after 0.3.0:

- Small models copied whole vault-outline lines ("Folder/Note — heading › heading") as note paths and then failed to find the note. Outline lines now name the file explicitly (`Note.md — …`), the prompt says the path stops at the dash, and every path-taking tool strips that decoration before giving up.
- Replies that cited notes as backticked paths (`Projects/Note.md`) are rewritten to clickable wikilinks (`[[Projects/Note]]`) when the path resolves to a note.
