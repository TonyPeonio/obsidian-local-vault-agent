The agent now finishes the job instead of stopping to ask.

- **Autonomous by default.** The system prompt tells the model to carry a multi-note task through to the end and never to ask "Would you like me to proceed?" — reading needs no permission and every write is already approved through the diff dialog.
- **Auto-continue.** When a small model still stops to ask for the go-ahead, the agent answers "yes, continue" for you (up to three times per message) and keeps going. A note in the chat shows when this happened. It never answers for you when the model offers a choice ("which one?", "A or B?") or after you rejected a change in that message. Toggle: *Settings → Agent → Keep going when the model asks for permission*.
- **Grounding check.** A reply that cites wikilinks to notes that do not exist is sent back once with "search the vault first" instead of being shown as if it were true.
- **`find_in_note` tool.** Locates lines in a long note by text or regex, with line numbers and context, so the model can target an `edit_note` without paging through the whole note.
- **Grounded edit retries.** When `edit_note` cannot find `old_text` (usually because the model guessed it from a search snippet), the error now lists the real lines that contain the most distinctive word, so the retry copies text that exists.
- **`list_files` and `delete_file` tools.** The agent can now see attachments (recordings, images, PDFs) and move any note or file to the trash according to your "Deleted files" preference, after approval.
- **Copy conversation.** A header button copies the whole chat — prompts, replies, tool calls and results — as markdown.
- Default *Max tool calls per message* raised from 15 to 40 (slider now goes to 100). Existing installs keep their saved value; raise it for multi-note clean-ups.
