Answers link the exact paragraph, the agent reads Lecture Companion's lectures and your images, quizzes you, links concepts across courses, runs scheduled jobs that wait for your approval, and keeps a change history you can undo from.

**Citing the passage, not just the note**
- **A *Passages* line under answers from notes** links the paragraphs the answer used: those it quotes, the transcript paragraphs whose `[m:ss]` it names, or ones it closely paraphrases. A paragraph with a block id is linked as `[[note#^id]]`.
- **Block ids are only written with your approval.** A paragraph without one gets an id proposed (`^t21-29` for the transcript paragraph at 21:29, a short hash otherwise); all of one answer's ids for a note are one diff. Reject it and the link points at the paragraph's heading (`[[note#Transcript|note › 21:29]]`), which needs no write. *Settings → Paragraph citations*: block ids, headings only, or off.

**Lecture Companion**
- **Lectures and transcripts as data.** With Lecture Companion installed (its API version 1), the agent gets `list_lectures` and `lecture_transcript`: the matching transcript paragraphs with their `[m:ss]`, instead of searching notes and following conventions in `AGENT.md`. Without it everything works as before.
- **Voice input.** A mic button in the chat records, converts to 16 kHz mono WAV and transcribes through Lecture Companion's whisper server into the message box. Without Lecture Companion the button is not shown.
- **One Ollama for both.** *Use Lecture Companion's Ollama settings* in settings copies its URL and model.
- **This plugin's own API**, `app.plugins.plugins["local-vault-agent"].api` (version 1): `openChatAbout(path)` and `ollama()`. Both APIs are documented in the README.

**Studying**
- **Quiz me.** *"Quiz me on CSCI 470 since October 1"* (or the command, or `/quiz`): questions written from those notes, asked one at a time, each answer graded against its source paragraph with the answer and a link to it; missed ones go to a review note after you approve the diff.
- **Suggest concept links for this note.** Concept or topic notes the open note mentions (or is close to by meaning) become links in one diff, optionally recorded as `parent`/`child` link properties for Branching Table of Contents, so one concept gathers lectures from every course.

**Images and scans**
- **`read_image`** reads an image (text, handwriting, diagrams, charts) or a scanned PDF page with a local vision model; `read_note` tells the model which images a note embeds and `read_file` which PDF pages are scans. Readings are cached by content hash. *Settings → Vision model*: empty uses the chat model when it can see (`qwen3.5` can), or set e.g. `qwen2.5vl:7b`; without one the tool is not offered.

**Scheduled jobs**
- **Nightly *Process my daily notes* and a weekly digest note**, off by default. They run when Obsidian is open at or after their time and never write: what they would change waits until you are back (a notice and a status-bar badge), then each change is a diff you approve. A note you edited meanwhile gets the change carried over when the edits do not overlap, and is skipped when they do.

**Change history**
- **Every approved change is kept** (the last 300, across restarts) with its time, chat and diff. *Show change history* (`/history`) lists them with an Undo button.
- **Undo keeps later edits.** If a note was edited after the change, only the change is taken back; if the later edits overlap it, the undo is refused instead of overwriting them. Deleting a note the agent created is refused once you have written in it. An undo can itself be undone.

**Benchmark**
- **Four new scenarios and a new check** (Lecture Companion tools, quiz, the nightly job in an overlay, reading an embedded image; a passage link on the transcript question): 32 of 34 checks with `qwen3.5:9b`. The misses are the model's: a queued topic note without its *Sources* section, and a drawn "47" read as "41". The full 24-scenario run was not repeated for this release.
- **The benchmark harness builds again**: it still imported the Vault Suggestions note writer that 0.6.0 removed.

**Only checkable inside Obsidian** (built and unit-tested, not exercised in a running Obsidian for this release): the mic button and recording (microphone permission, MediaRecorder decoding), rendering scanned PDF pages for the vision model, the change-history and concept-link dialogs, the status-bar badge and the reminder notice, scheduled jobs firing on their timer, and the Lecture Companion API calls against the real plugin (its side was built in parallel to the same interface; here it was exercised through a fake that follows the specification).
