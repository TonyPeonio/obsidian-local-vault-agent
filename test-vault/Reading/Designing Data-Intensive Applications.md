# Designing Data-Intensive Applications

Chapter notes.

## Ch 1 Reliability, scalability, maintainability
Reliability means tolerating faults, not preventing them. Scalability is about load parameters.

## Ch 3 Storage engines
LSM trees vs B-trees. LSM: fast writes, compaction cost. B-trees: predictable reads.
